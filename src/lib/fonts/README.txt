TailorBidSans-Regular.ttf and TailorBidSans-Bold.ttf are a Modified Version of Carlito
(https://github.com/googlefonts/carlito, Copyright 2013 The Carlito Project Authors), licensed under the
SIL Open Font License 1.1 (OFL.txt).

Changes: trimmed to the Windows-1252 (WinAnsi) characters the PDF renderer draws, hinting and OpenType layout
features removed, and renamed because "Carlito" is a Reserved Font Name. Carlito has the same letter widths as
Calibri, so PDFs line-break like the Calibri Word files. Used by src/lib/documents.ts.
